# 👑 Royal Indian Wedding Invitation | ॥ शुभ विवाह ॥

An elegant, interactive, and mobile-responsive Royal Indian Wedding Invitation web application designed with regal Maroon & Gold aesthetics, traditional Devanagari typography, smooth GSAP animations, and dynamic synthesized Shehnai & Sitar music powered by Tone.js.

## ✨ Features

- 🪷 **Auspicious Beginnings:** Traditional Ganesh Vandana & Sanskrit Shlokas.
- 👑 **Regal Aesthetic:** Curated Indian royal wedding color palette — deep imperial maroon, shimmering gold accents, and ornate palace motifs.
- 🎶 **Live Synthesized Shehnai & Sitar:** Audio generated on the fly via **Tone.js** — no external audio files required!
- 📜 **Wedding Itinerary & Functions:** Detailed ceremony schedule covering Haldi, Mehendi, Sangeet, Baraat, Shubh Vivah (Pheras), and Grand Reception.
- 📍 **Venue & Location:** Interactive map card with one-click navigation to the palace venue.
- 💌 **Digital RSVP & WhatsApp Integration:** Guests can submit their RSVP and instantly confirm via WhatsApp.
- 📱 **100% Mobile Responsive:** Flawless experience across phones, tablets, and desktops with smooth scroll and GSAP entrance effects.

2. Under **Branch**, select `main` and `/ (root)`.
3. Click **Save**.
4. Your invitation will be live at:
   ```
   https://<your-username>.github.io/<repository-name>/
   ```

## 💻 Local Setup & Development

No complex build steps or dependencies needed!

1. **Clone the repository:**
   ```bash
   git clone git@github.com:ManavKhairal/royal-wedding-invitation.git
   cd royal-wedding-invitation
   ```

2. **Open in browser:**
   Double click `index.html` or run:
   ```bash
   # Using Python built-in server:
   python3 -m http.server 8000
   ```
   Then open `http://localhost:8000` in your browser.

## 🎨 Tech Stack

- **Markup:** HTML5 with semantic structure and Open Graph tags.
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) & Vanilla CSS custom animations.
- **Animations:** [GSAP 3 & ScrollTrigger](https://greensock.com/gsap/).
- **Audio Engine:** [Tone.js](https://tonejs.github.io/) for synthesizing Indian classical Shehnai & Sitar melodies.
- **Fonts:** *Rozha One*, *Yatra One*, *Cinzel Decorative*, and *Tiro Devanagari Hindi* (via Google Fonts).
- **Icons:** [FontAwesome 6](https://fontawesome.com/).
